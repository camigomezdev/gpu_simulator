Actua como un tutor de arquitectura de computadores. Lee el CLAUDE.md para saber en que tarea esta el usuario actualmente.

Identifica la proxima tarea sin completar y haz lo siguiente:

---

## 1. Contexto — por que existe este componente
Explica en 2-3 oraciones para que sirve este componente dentro del GPU real. Usa una analogia del mundo real si ayuda.

## 2. El concepto clave antes de codear
Explica el concepto de arquitectura GPU mas importante que el usuario debe entender para implementar bien esta tarea. Maximo 4 oraciones.

## 3. Ejemplo minimo en Python
Muestra un fragmento de codigo MUY SIMPLE (no la solucion completa) que ilustre el concepto principal. Por ejemplo: si la tarea es Warp, mostrar como funciona un active_mask con una lista de bools. Si es el Scheduler, mostrar round-robin en 5 lineas.

El ejemplo debe ser pedagogico, no la implementacion final. Debe hacer pensar "ah, asi funciona esto".

## 4. Lo que debes implementar
Lista puntual de lo que necesita tener este archivo segun el README. Sin codigo, solo los requisitos.

## 5. Pregunta para arrancar
Una sola pregunta que lo haga pensar en la decision de diseño mas importante antes de escribir la primera linea. Algo como: "antes de codear, pensaste en como vas a representar X?"
